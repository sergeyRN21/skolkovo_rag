# 🏢 Консультант по Сколково — RAG-система для нормативных документов

**Автоматизированный ИИ-ассистент для быстрого поиска ответов на вопросы по правилам Фонда «Сколково»**  
*Полнофункциональная production-grade RAG-система с аудитом, резервным копированием и RBAC*

---

## 🔧 Технологии
- **RAG Pipeline**: LangChain + LangChain-Chroma + HuggingFace BGE-M3
- **LLM**: OpenRouter (Gemini 2.5 Flash)
- **Хранение**: ChromaDB (векторная база), YAML/JSON (метаданные)
- **Интерфейс**: Streamlit с админ-панелью
- **Безопасность**: bcrypt, RBAC (user/editor/admin), логирование
- **Надежность**: Автоматическое резервное копирование (ZIP + очистка старых)

##  Особенности
- ✅ **Интеллектуальный ретривер**: адаптивный поиск по типу вопроса (сроки, санкции, льготы и т.д.)
- ✅ **Гарантированная цитируемость**: автоматическое расширение сокращённых ссылок (например, `337-Пр` → полное название приказа)
- ✅ **Пост-обработка**: дедупликация, грамматика, удаление артефактов
- ✅ **Шаблоны ответов**: регулярные выражения для повторяющихся вопросов
- ✅ **Аудит и traceability**: полный журнал запросов (CSV), логирование источников
- ✅ **Управление контентом**: загрузка/удаление PDF, автоматическая индексация
- ✅ **Резервное копирование**: `backup.py` — полный бэкап базы, данных, логов и настроек с автоочисткой

## ⚙️ Запуск
```bash
pip install -r requirements.txt
streamlit run main.py

💡 Первый запуск:
Приложение автоматически создаст необходимые папки (data/, logs/, backup/, chroma_skolkovo/) и проиндексирует все PDF-файлы из папки data/.
Для работы требуется валидный API-ключ OpenRouter (установите OPENROUTER_API_KEY в .env).
```

##  Аутентификация

Пользователи создаются через Админ-панель → Пользователи → Добавить пользователя.

По умолчанию доступа нет — первый администратор должен быть создан вручную.

Роли: user (только чат), editor (чтение + правки), admin (полный доступ).

🛡️ Надежность & Production-готовность

✅ Полное резервное копирование: backup.py архивирует всю систему — базу, данные, логи, настройки.

✅ Аудит и traceability: Все запросы, ответы, источники и изменения логируются в CSV.

✅ Гарантия цитируемости: Автоматическое расширение ссылок (например, 337-Пр → полное название приказа).

✅ Отказоустойчивость: Fallback на шаблоны при низкой уверенности RAG; обработка ошибок LLM.

✅ SLA-ориентировано: Адаптивный ретривер (разные параметры по типу вопроса: сроки, санкции, льготы).

✅ Поддержка A/B тестирования: Через шаблоны и историю правок.

Идеально для регулируемых сред — где каждый ответ должен быть аудитируемым, обоснованным и не допускать галлюцинаций.

Полностью self-contained: все данные, код и настройки — в одном каталоге, готовом к бэкапу и восстановлению.
